# AniTexas 标签黑名单词表（P4 筛子二「太格式化」）
# 版本: v1
# 说明: 词表属于配置不属于代码（architecture.md §4.6 注）。build_cards.py 每次运行会把版本号写进
#       data/pipeline-report.md，词表改动必须 +版本号。
# 集合内容参考 bak/anitexas-verify.py（原型）的 FMT / TYPE_FORM / PERSON_NAMES / STUDIO_ALIASES。
#
# 格式:
#   「# ==== 类别 ====」开启一个类别；类别只有四个: 格式标签 / 年份形式 / 公司名·人名 / 原作类型形式
#   「#」开头与空行忽略
#   年份形式  -> 正则（对标签整串 fullmatch）
#   公司名    -> 「别名=规范名」；标签命中任一别名即剔除（归入「公司名·人名」），
#                制作公司字段命中别名则归一为规范名（京阿尼=京都动画一类）
#   人名      -> 裸词条；标签命中即剔除（与公司名同属「公司名·人名」类）
#   原作类型  -> 「原始形式=五值归一名」；标签命中即剔除（归入「原作类型形式」），
#                meta 标签/标签命中同一词表时按五值归一产生原作类型要素
#
